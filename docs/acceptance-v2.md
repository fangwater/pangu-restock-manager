# 一期验收记录（2026-10-11）

按需求文档参考修改；一期沿用团队入口，二期分仓只预留模型。

| 验收项 | 实现与验证 |
|---|---|
| AC1 时间筛选 | 7/30/90 天、季度、自定义起止日期；Python 测试校验含首尾天数与日期边界，浏览器校验查询/重置。 |
| AC2 类目下钻 | 衣架/脏衣篓/待分类总览下钻到 SKU，类目内占比与全局占比分开；完整维度两位小数合计 100%。 |
| AC3 店铺覆盖 | HOME/BUY/Shein 默认全量，多选筛选；隔离 PostgreSQL 测试验证新增店铺自动进入快照。 |
| AC4 件数口径 | SUM(quantity) 用于销量占比；warehouse_quantity 单独作为采购需求。取消/退款/无效单剔除，独立 SQL 接口测试含数量换算差异。 |
| AC5 备货建议 | 默认 30 天、20% 缓冲，扣可售库存/可选在途，按可配置箱规向上取整；测试验证规则继承、人工编辑、锁定与未锁定草稿重算、并发版本保护。 |
| AC6 Excel | 异步导出标准 XLSX，4 张工作表；浏览器下载、ZIP/XML 完整性和 openpyxl 兼容性验证，数字为数值单元格，锁定计划保留原始依据。 |
| AC7 二期预留 | 快照 region/warehouse、计划 region/warehouse、NY/ATL/HOU/LA 州映射配置结构。未确认州规则，不自动分仓。 |

验证覆盖：18 项 Python 测试通过；中台 `go test -race ./...` 在隔离 PostgreSQL 集群执行通过；Go 构建成功。隔离浏览器完成保存、锁定、重算、资料/箱规、类目规则、新类目、Excel、空数据和移动端操作验证。生产页面验证使用只读业务操作及导出，不创建测试采购计划。

升级保留旧计划数量、版本、备注并默认锁定；上线前用 SQLite backup API 备份，并在备份副本上验证迁移。中台接口只提供聚合数据，不输出客户信息。

性能实测：香港本地缓存报表 30/90/366 天约 0.07–0.08 秒；公网 90 天报表启用 Nginx 压缩后约 1.2 秒、16 KB。未做百万订单压力测试，此结果不代表百万规模性能承诺。

数据限制：部分 Temu 历史订单无平台下单时间，沿用首次采集日期；自动识别产品资料可人工修正；缺少库存映射不虚构零库存，暂停该 SKU 自动建议。默认有效单包含待发货，可通过状态筛选仅查看已发货/已完成。
