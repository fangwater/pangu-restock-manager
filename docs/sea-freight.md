# 海运账单与柜级费用

采购单使用 `shipping_order_no`（托单号）、`bill_of_lading_no`（提单号）；海运账单使用原表中的托单号/订单号、提单号。两个字段分别保存，原库存单号保持独立。

采购单编辑及采购 CSV 支持两个识别号；旧 CSV 未提供这两列时保留已有值，明确导入空白列则清空。海运 Excel 导出保留原表 35 个业务列及明细分组，追加入仓口径、补充关联采购单、版本、参考汇率。采购单编号变更在读取海运账单时重新匹配。

匹配忽略首尾空格和字母大小写，不删除标点或做模糊匹配。一个柜子可以匹配多个采购单。两个非空编号相互矛盾或匹配多个海运账单时标记冲突；补充关联同一采购单至多个海运账单时要求分摊。

柜级费用为采购 SKU 货款合计加海运账单原币金额，按币种展示。已有采购附加费用单列，不再相加。缺少关联、货款金额/币种或账单合计，以及编号冲突、跨柜未分摊时，不计算柜级合计。该报表不自动写入 SKU / FIFO 成本。

海运账单通过 Excel 预览后整批提交，保存原文件、SHA256、来源凭证及前后版本。相同文件重复导入不覆盖后续核对；导出文件带版本号，过期修改拒绝导入。未出现在文件里的账单保留。金额只通过 Excel 导入更新；页面可核对付款、入仓日期口径及补充采购单关联。

仅导入海运明细，不累计汇总、报价、一口价辅助估算或异常页金额。原币空白保持未提供，付款待确认不解释为欠款。原始异常说明保留并独立展示。导出的付款计划及参考折算按账单原币重新计算，原文件不改写。

API：`GET /api/sea-freight`、`GET /api/sea-freight/bills/:id`、`PUT /api/sea-freight/bills/:id`、`POST /api/sea-freight/import/preview`、`POST /api/sea-freight/import`、`GET /api/sea-freight/export.xlsx`、`GET /api/sea-freight/files/:id`。写入沿用同源及请求头校验。XLSX 仅支持不超过 6 MiB 的文件与已保存公式计算值。
