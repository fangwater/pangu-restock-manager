# 界面统一与销量构成图（2026-10-11）

筛选区使用统一网格布局：所有标签和控件分别对齐，控件高度 36px。宽屏日期、店铺、类目、状态、查询同排；中屏日期独占一行，其余筛选同行；手机分两列。移除互相覆盖的旧样式，统一灰白背景、蓝色操作色、字号、边框和间距。

四项统计合并为一组指标；类目和店铺销量构成使用同一图表区的两个 Apache ECharts 环形图，销量趋势使用同库折线图。图例显示件数和两位小数占比，扇区和图例均可下钻；类目图始终使用全类目分母。小占比保留真实角度，零销量显示空环，不虚构扇区。无数据的默认待分类不占图例位置。

一并统一 SKU 表格、分类目录、规则列表、抽屉、弹窗和空状态。数据连接页从多张卡片改为状态表。供应商脚本随项目部署，ECharts 6.0.0 附 LICENSE/NOTICE，不依赖运行时 CDN。

待分类商品核对：`SP+D-1PC-41CM` 名称为西语烘烤托盘，`SP+D-2PCS-41CM` 明确标注烤盘，`SP+D-4PC-41CM` 为不锈钢 Baking Pan。配置新增烤盘类目、托盘图标、`SP+D-` 前缀及中英西文关键词；三个已核对 SKU 通过分类接口确认归属。配置仍保存在数据库，初始化文件不覆盖已维护类目。
